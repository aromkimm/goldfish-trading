# 등록 에이전트 검증 근거

- 유형: 구현·상품 검증. 확인 기간: 2026-10-12~2026-10-14.
- 용도: 구조 검사·상품 의미 검수·화면 확인·판매 효과를 구분하고 미검증 범위를 재검증하기 위한 기록.
- 실행 방법: [사용법](../agents/product-listing/README.md), 검수 기준: [작업 절차](../agents/product-listing/workflow.md).

## 가설

상품 사실·검색 판단·콘텐츠·검수를 같은 버전으로 연결하면 근거 없는 등록 자료와 미완성 결과의 승인 오류를 줄일 수 있다. 시간 절감·판매 효과는 별도 검증 대상이다.

## 검증 방법

- 로컬 Python의 자동 시험과 합성 자료의 prepare → validate → build → check → review 흐름을 실행했다. 실제 상품 승인을 시험 승인으로 대신하지 않았다.
- 도매매 [데스크 매트 23824864](https://domeme.domeggook.com/s/23824864)와 [바구니 67434894](https://domeme.domeggook.com/s/67434894)의 보관·공개 원문 및 이미지를 읽고 사용자 지정 판매 범위와 대조했다.
- 별도 사진 시안을 로컬 HTTP·Chrome의 PC 1280×900, 모바일 390×844에서 확인했다〔확인된 검수 환경, 2026-10-13〕. 화면 캡처와 DOM 표시 폭을 대조했다.
- 2026-10-14 네이버 공식 키워드 도구의 최근 한달 통합검색수와 가격비교 검색·경쟁 상세를 조사했다. 핵심 검색어 15개·쇼핑 검색어 7개, 경쟁 상세 4곳, 새 태그 후보 10개·기존 태그 4개를 조사 범위로 기록했다〔확인된 조사 범위; 전수 조사 아님〕. 태그 수요는 같은 로그인 세션에서 PC·모바일 표시값을 대조했다.
- 로그인 판매자센터에서 카테고리·속성 목록·태그사전을 조회했다. 조회용 입력은 저장·임시저장하지 않았고 광고 생성·집행·게시·발주도 하지 않았다.

### 통합 생성 회귀 확인

2026-10-14 코드·사진 생성 경로 통합을 다음 범위에서 확인했다〔이번 실행값〕.

- 현재 계약 시험 35개 통과. 이전 계약 전용 구현·시험 자료를 제거하기 전에 필요한 CLI 오류·필수값 차단·자산 참조 검사를 현재 시험으로 옮겼다. 과거 계약의 시험 수와 직접 비교해 품질 향상을 주장하지 않는다.
- 두 v8 등록안의 상품명·카테고리·태그를 포함한 fields, 검색 후보·판단, 경쟁 관측, 출처·기존 사실, 채널 확인 내용과 미결 과제를 통합 전후 대조해 유지했다. 자료 파일·사진을 제외한 [매트](../agents/product-listing/tests/fixtures/desk-mat.json)·[바구니](../agents/product-listing/tests/fixtures/basket.json) 입력으로 선정 데이터·출력 회귀를 재현한다. 이 입력은 최신 조사 자료나 게시용 원본이 아니다.
- 기존 사진 시안의 매트 12영역·바구니 11영역을 공통 build로 생성했다. 원본 이미지 바이트를 유지했다. 바구니의 충돌 중인 린넨 명칭은 본문에서 빼고 공급처 세탁 기재를 별도 사실로 연결했으며, 소재·관리법 확인 과제는 유지했다.
- Chrome 로컬 PC 1280×900·모바일 390×844에서 사진 로딩·도입 순서·줄바꿈·표·규격 도식·작은 사진 묶음을 확인했다. 사진 디코딩 실패·가로 넘침·영역 해상도를 넘는 표시 폭은 없었다. 고밀도 선명도·실제 판매자센터·상품 사실 전체의 검수는 아니다.
- 기존 layout 없는 v8 패키지의 check, 새 패키지의 check 및 영역·문구 변경 후 검수·승인 초기화를 확인했다. 사진이 보여도 미확인 사용·편집 권한은 게시 차단으로 남았다.

재검증 자료: [매트 통합 패키지](../agents/product-listing/runs/23824864-integrated-v2-package/listing-package.json) · [바구니 통합 패키지](../agents/product-listing/runs/67434894-integrated-v2-package/listing-package.json) · [화면 크기·버전·해시·사진 검사](../agents/product-listing/runs/integrated-review/screen-review.json). 화면 캡처와 해당 버전 desktop/mobile 검수 보고는 같은 검증 폴더에 있다. 로컬 자료는 Git 제외 대상이다.

### 검색·등록 판단

2026-10-14 조사에서 매트의 상품 종류에는 통합검색 수요가 있었지만 규격·색상 조합의 독립 수요는 작게 표시됐다. 조건어는 정확한 상품 선택 정보로 유지했다. 바구니 검색에는 플라스틱·누빔·대형 수납이 혼재해 해당 수요를 이 상품의 예상 고객 수로 대입하지 않았다.

경쟁 상세·검색 결과·태그사전·추가 수요를 대조한 뒤 매트의 책상깔개는 제품 용도 보완으로 채택했다. 검색량만으로 사무실책상꾸미기나 패브릭바스켓으로 교체하지 않았다. 제목 동의어 교체·나열의 성과 우위는 입증하지 못했다. 바구니의 소재·옵션 충돌은 검색 수요로 해소되지 않아 상품 재검토 의견을 유지했다.

카테고리·태그와 속성 목록은 확인했지만 고시·인증·전체 필수값·상세 표시 검수는 마치지 않았다. 당시 최종 등록안은 두 상품 모두 부분 초안·게시 보류였으며 실제 승인은 없었다.
