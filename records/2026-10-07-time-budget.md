# 사업 계획의 판단 근거

- 유형: 결정. 근거 기간: 2026-10-07~2026-10-10.
- 출처: 사용자가 제공한 기획 요약과 전달한 금붕부부 합의. 대화 원문이 아닌 당시 기록의 요약이다.
- 용도: [첨부 요약과의 충돌](2026-10-12-listing-mvp.md)을 판단하고 초기 개발 범위의 이유를 재검토하기 위한 근거. 현재 기준은 [PROJECT.md](../PROJECT.md)를 따른다.

## 가설

초기 자원과 개발 범위를 제한하고, 판매 성과·운영 부담을 관찰한 뒤 확대 여부를 판단할 수 있는가.

## 검증 방법

기획 요약과 사용자 전달 합의를 대조했다. 사업성·실제 투입 시간·주문량에 대한 실측 검증은 수행하지 않았다.

## 결과

| 근거 시점 | 확인된 합의·가정과 한계 |
| --- | --- |
| 2026-10-07 기획 요약 | 별도 수익 목표 없이 3개월 관찰, 시작 3개월 후 판매 패턴·6개월 후 월 순이익과 운영 시간 검토〔합의된 계획값〕. 관찰 시작일은 미정 |
| 2026-10-07 사용자 합의 | 주당 시간은 각자 7시간, 사업자 명의는 금붕녀. 필요한 항목만 최소한으로 지출〔합의된 계획값·방침〕. 시간·명의 선택의 별도 사유는 전달되지 않음 |
| 2026-10-07 사용자 확인 | 회사 겸업 규정상 진행 가능. 규정 원문을 에이전트가 직접 검토한 것은 아님 |
| 2026-10-07 조사 착수 | 행정 준비와 후보 조사를 구분해 조사부터 진행. 세부 예산·시간 조건·관찰 기산점의 미결은 조사 착수를 막지 않음 |
| 2026-10-10 공동 합의 | 추천은 금붕남, 등록은 금붕녀가 독립 개발. 첫 사용 사례·입출력·구현 범위·검증 기준 정하기를 담당자의 개발 실무에 포함. 금붕녀가 스토어 개설 |
| 2026-10-10 개발 범위 판단 | 판매 여부가 불확실하고 초기 대량 주문을 예상하지 않아 판매 이후 운영 개발을 후속으로 둠. 주문량은 사용자 가정이며 실적 아님. 추천·등록에 집중하고 행정·자금 준비는 사람이 수행 |

## 다음 결정

사업 기준 변경은 금붕부부가 판단한다. 첨부 요약이 위 합의를 변경하는 공동 결정인지 확인하기 전에는 새 수익·시간·시작일을 확정하지 않는다.

## 지금 알게 된 것

자원 계획과 개발 범위는 사용자 합의이며, 운영 시간 절감이나 판매 가능성이 입증된 결과가 아니다.

## 아직 모르는 것

당시 구축 기간의 시간 적용 여부·구축 후 허용 운영 시간·예산과 손실 한도·관찰 기산점·후속 업무 위임 범위는 미정이었다. 현재 남은 결정은 [STATUS.md](../STATUS.md#미결-과제)에서 관리한다.
