# 책상 매트 등록 패키지

**콘텐츠: A(원본 유지) · 게시: 보류 · 사람 승인: 미요청**

필드·문구·원본 목록·근거·확인 과제·검수 결과를 갖춘 수동 제작 기준 예시다. 확인되지 않은 입력값이 있어 실제 판매 등록 준비 완료를 뜻하지 않는다.

이 문서는 [listing-package.json](../../../agents/product-listing/examples/23824864/listing-package.json)의 읽기용 파생본이다. 상품 사실·필드·문구·확인 과제의 관리 원본은 JSON이며, 변경 시 이 문서와 [미리보기](preview.html)를 함께 갱신한다. 네이버 API 요청 형식이 아니다.
