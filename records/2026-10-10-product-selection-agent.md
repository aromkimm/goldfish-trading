# 상품 추천 에이전트의 결정·검증 근거

- 유형: 결정·구현·표본 검증. 근거 기간: 2026-10-10~2026-10-14.
- 출처: 사용자가 전달한 금붕부부 결정과 당시 실행 기록. 대화·API 원응답 전체 보존본은 아니다.
- 용도: 제외 기준·추천 범위와 데이터 소스 선택의 이유, 포화도·가격 계산의 한계를 재검증한다. 현재 설계는 [추천 에이전트](../docs/product-selection-agent.md), 상태는 [STATUS.md](../STATUS.md)에서 관리한다.

## 가설

검색 수요와 경쟁 판매자·가격 자료로 도매매 후보를 좁히고 판매 조건을 확인할 수 있는가. 11번가의 경쟁 자료가 네이버 판매 후보를 비교하는 데 유용한가는 별도 가설이다.

## 검증 방법

API 실호출·오프라인 시험으로 파싱과 계산을 확인하고, 도매 후보와 11번가 검색 결과를 비교했다. 네이버 대조는 금붕남이 제공한 검색 화면 표본을 사용했다. 실판매·업무시간 개선 검증은 수행하지 않았다. 아래 건수·시간은 각 확인일의 당시 실행값이며 현재 데이터 수나 성능 보장값이 아니다.

## 결과

### 사업 결정과 적용 범위

- 2026-10-10 공동 결정: 추천 에이전트는 판매 실적을 기다리지 않고 개발한다. 초기 제외 기준안을 확정 적용하고 판매 경험 후 재정비한다. 같은 상품 판매자 수를 핵심 비교 지표로 추가했다.
- 무재고의 손실이 시간뿐이라는 사용자 가정은 미검증이었다. 반품비·도매 선결제·수수료 등 비용 때문에 예산·손실 한도의 미결 상태는 유지했다.

### 범위 재정의 — 2026-10-10

- 사용자 전달: 금붕남은 상품 추천과 판매 가능 조건 확인, 금붕녀는 등록·상품 관리·운영 개발을 맡는다. 개발 담당과 주요 사업 결정권은 구분한다.
- 추천 결과에 옵션·공급가, 품절·출고·주문 마감, 배송·추가배송·묶음배송, 교환·반품, 이미지 사용 범위, 인증·표시·판매 제한을 확보한다. 배송·반품 조건 불일치 또는 필요한 정보 미확보면 선정 단계로 반려한다.
- 출고 지연·이미지 불허를 무조건 반려하자는 에이전트 제안은 채택하지 않고 주의 표시로 정리했다. 추천 통과가 실제 게시 승인은 아니다.
- 사용자는 수동 지표 입력 부담을 받아들이지 않았고 분석 데이터를 네이버에 한정하지 않기로 했다. 추천 지표는 자동 수집하고 사람 입력은 표본 대조에 사용한다. API로 얻지 못하는 판매 조건은 별도 사람 확인으로 남았다.

### 데이터 소스 선택과 실호출 — 2026-10-10

- 네이버 개발자센터 앱 목록과 공식 공지 32530·32564를 통해 쇼핑 검색 API의 2026-07-31 종료·대체 없음·기존 키 호출 불가를 확인했다. 개편 전 GitHub 문서만으로 현행 API를 판단했던 오류 때문에 제공 목록·공지·실호출을 함께 대조했다. 공식 출처는 [데이터 출처](../docs/product-selection-agent.md#데이터-출처)에 연결했다.
- 사용자 결정: 네이버쇼핑 크롤링은 하지 않는다. 경쟁·가격은 11번가, 추세·관심도는 NAVER API HUB로 수집한다. 도매처 가격비교 값은 후보 152개 중 4개뿐이어서 대체 소스로 부족했다.
- 검색광고는 비즈머니 미충전 계정에서 라이선스 발급·키워드 호출에 성공했고 검색수가 숫자로도 반환됐다. 도매꾹 목록·상세 호출에서 문자열 숫자·수량별비례 배송비를 확인해 한 개 주문 비용 계산에 반영했다.
- 11번가 실호출은 등록 IP에서 확인했다. NAVER API HUB는 쇼핑 인사이트·검색어 트렌드·블로그·카페·이미지 검색을 확인했다. 당시 접근·요금 조건은 현재 계정의 이용 가능성을 보장하지 않는다.
- 도매 상세에서 주문 마감·반품 접수 방법은 API로 확보하지 못했다. 무료배송 판매 시 반품비 배수, 최저판매준수가, 이미지 허용 범위를 판매 조건에 반영했다. `denyMarket`과 옵션 필드 해석은 미확인으로 남았다.

## 네이버 대비 표본 검증과 판정 보정 — 2026-10-14

- 방법: 에이전트 브라우저(내장·Claude in Chrome)는 네이버쇼핑 접근이 안전 정책으로 차단돼, 금붕남이 상품명 검색 화면을 캡처하고 에이전트가 분석했다. Playwright 등 우회 자동화는 차단 우회·봇 탐지 회피에 해당해 하지 않았다.
- 결과(4건): 드라이기 거치대·트렁크정리함 2건은 11번가 같은 사진 0~1명이었고 네이버에서도 같은 사진은 없었으나, 같은 유형 상품이 다수이고 상위는 리뷰 수천 개 판매자·가격비교 묶음(판매처 최대 87곳)이었다. 철제선반은 11번가 같은 사진 13명, 네이버 25곳 이상(가격비교 묶음 17곳)으로 방향은 같고 숫자는 약 절반이었다. 철제선반은 대표 키워드 검색 의도(앵글 랙)가 상품(인테리어 선반장)과 달랐다. 네이버쇼핑에는 11번가·롯데ON 상품이 함께 노출된다.
- 보정: 포화도를 같은 유형 판매자 수(상품명 80% 일치)로 바꾸고 경쟁가에 같은 유형 가격을 썼다. 추천 조건에 경쟁 중앙가 기준 마진 15% 이상·경쟁가가 같은 사진/유형 기준을 추가했다. 대표 키워드 4건을 교체했다(철제선반→철제책장, 모듈수납장→접이식수납장 2건, 틈새수납장→플라스틱서랍장). 표본 4건 모두 추천에서 빠졌다.
- 아직 모르는 것: 진입 장벽 자동 측정(11번가 리뷰는 거의 0), 같은 유형 임계값의 적정성, 추천 상위 후보가 실제로 경쟁이 덜한지(좋은 상품 쪽 정답 표본 없음).

## 좋은 쪽 표본 검증과 네이버 보정 — 2026-10-14

- 추천 상위 4개 캡처: 접이식카트는 같은 사진 약 11건·묶음 없음으로 측정과 맞았다(조건부 가능). 무타공 벽선반은 판매자가 적지만 최저가 8,920원이 원가 13,130원보다 낮았다. 택배보관함은 네이버 최저가 89,210원으로 마진 약 1%. 욕실선반은 같은 사진 25건 이상·가격비교 묶음 55곳의 레드오션이었다.
- 보정: 같은 사진이 양쪽에 있던 표본 5개의 네이버÷11번가 비율 평균으로 최저가 ×0.76, 중앙가 ×0.91을 적용하고, 추천 조건에 경쟁 최저가 기준 적자 아님을 추가했다. 추천은 20개에서 9개로 줄었고 네이버에서 부적합으로 본 3개가 빠졌다. 보정 후 최저가 기준 적자 후보는 140개 중 129개다.
- 남은 추천 9개는 원가 3,490~19,110원의 저가 상품이 대부분이고 같은 유형 판매자가 많으며(32~87), 검색량이 작은 것도 있다(140~210).

| 최저판매준수가 효과 | 같은 입력의 보정된 경쟁 최저가 4,560원·중앙가 5,915원이 준수가 적용으로 모두 10,000원이 되고 수수료 전 마진율 30% 계산. 준수가만 없애면 `recommended=false`. 준수가 준수 자체는 필요하지만 고객의 가격 수용성 근거가 되지 않음 |
| 검색수 범위값 | `_search_volume({'pc': naver.LESS_THAN_10, 'mobile': 1000})`이 `(0, '<10 포함')` 반환. 일부 범위값 때문에 알려진 모바일 검색수까지 계산에서 사라짐. 범위값을 영으로 대체하지 않는 기준과 불일치 |
| 경쟁 가격의 비교 조건 | `elevenst.parse`는 배송 설명을 읽지만 `saturation.match/same_type`과 `pipeline.compete`의 가격 배열에는 상품 표시가만 남음. 같은 사진/단어 겹침을 동일 옵션·수량으로 확인하는 절차 없이 무료배송 판매가와 비교. 실제 왜곡 크기·방향은 원자료 없어서 모름 |
| 검토의 적용 범위 | `import_review`는 근거·리스크·모름을 저장하며 `build_rows`의 추천 여부를 바꾸는 판정은 아님. 실행 스킬의 별도 검토가 필요하고 최종 인계 품질은 실제 결과물 없어서 판정 불가 |
| 보정의 독립 검증 | 기존 기록의 네이버 표본을 본 뒤 가격 보정·추천 조건을 변경. 그 표본에서 부적합 후보가 빠졌다는 결과는 수정 확인이며 새 상품 성능 측정이 아님. 표본별 전체 원자료·비추천 정답·단순 기준선 성능은 없음 |

판정: **후보 비교 도구의 작동 근거는 있으나, 팔릴 만한 상품을 잘 추천하는 성능은 입증되지 않았다.** 위 합성 사례는 가능한 실패 조건을 보여주며 최신 실제 추천 전체의 실패율을 뜻하지 않는다. 당시 상위 표본의 부적합 관측도 표본 선택 편향·보정 재사용 때문에 전체 정확도로 환산하지 않았다. 구현·가중치·사업 기준은 이 평가로 변경하지 않았다.

## 다음 결정

금붕남은 추천 상위 후보와 판매 조건을 검증하고, 금붕부부는 상품·가격·실험 범위를 판단한다. 도구의 임계값·가중치·수수료·포화도 정확도를 확인해야 한다. 사전 평가에서 재현한 가격·검색수·미확인 처리 문제를 개선 대상으로 검토하고, 에이전트는 실제 결과물 확보 후 보정에 쓰지 않은 후보를 추천·비추천 및 단순 기준선과 대조한다. 실판매 비교의 수량·기간·손실 한도는 금붕부부 결정 대기다.

## 지금 알게 된 것

여러 API로 후보 비교 자료를 만들 수 있지만, 같은 사진이 적다는 관측만으로 경쟁이 적다고 판단할 수 없다. 추천과 판매 조건 검사는 실제 채널의 게시 승인과 별개다.

## 아직 모르는 것

좋은 쪽 표본 4건 외의 정답 표본, 네이버 보정 계수의 안정성(표본 5개), 같은 유형 판정 정확도·네이버 진입 장벽, 판매 성과·운영 시간 개선. 당시 실행 자료는 Git 제외 `data/`에 저장됐으며 다른 체크아웃에서 원응답까지 재현할 수 있는지는 확인되지 않았다.
