# 상품 선정 에이전트 착수 및 선정 기준 결정

- 작성일: 2026-10-10.
- 유형: 결정. 상태: 결정 반영 완료, API 확인·구현 미실행.
- 근거: 이 대화에서 사용자가 전달한 금붕부부 결정.
- 관련 기준 문서: [상품 선정 기준](../docs/product-selection.md), [상품 선정 에이전트](../docs/product-selection-agent.md), [실행 계획](../docs/execution-plan.md).

## 가설

같은 도매 상품을 여러 판매자가 동시에 파는 위탁판매에서는, 수요가 있으면서 동일 상품 판매자가 적은 상품을 골라야 경쟁력이 생긴다.

## 검증 방법

미실행. 에이전트 구현 후 표본으로 포화도 측정 정확도를 확인하고, 등록 상품의 노출·주문 결과와 대조한다.

## 결과

- 에이전트 개발 시점: 기존 원칙(수동 검증 후 개발)을 상품 선정 에이전트에는 적용하지 않고 지금 개발한다. 사용자 근거: 수익률보다 실행에 의의를 두며, 위탁판매 손실은 시간뿐이고 여가시간으로 충당한다.
- 에이전트 이견: 무재고여도 반품 배송비·품절 취소 페널티·도매 선결제 자금·수수료 등 금전 손실 가능성이 있어 "손실은 시간뿐"은 검증되지 않은 전제다. 비용 확인과 예산·손실 한도는 기존 미결 과제로 유지했다.
- 적용 범위: 위 결정은 상품 선정 에이전트에 한정해 반영했다. 품절·단가 동기화와 등록 자동화는 기존 착수 조건을 유지한다.
- 판매가: 최저가·경쟁 중앙가를 모두 시도한 뒤 전략을 정한다.
- 초기 제외 상품군: 기존 기준안을 그대로 확정 적용하고 판매 경험 후 재정비한다.
- 동일 상품 포화도를 핵심 지표로 추가했다.
- 데이터 API 공식 문서 확인 시도(2026-10-10): 네이버 개발자센터·검색광고 API 문서는 조회 실패, 도매매 API 문서는 검색되지 않음. 모든 API 조건은 모름.

## 다음 결정

- 결정 주체: 금붕부부 공동. 구현·API 계정 발급 담당은 미배정.
- 후속 행동: API 접근 조건 확인 → 구현 → 후보 비교표 산출 → 금붕부부 선정.
- 대기: 포화도·검색량·경쟁 밀도 임계값, 가중치, 판매가 전략, 구현 담당.

## 지금 알게 된 것

상품 선정 에이전트의 착수 시점, 판매가 비교 방식, 제외 기준, 핵심 지표, 운영 방식(승인 후 등록), 베타 조건(20개·8주·수동 업로드·방치 기본·최소 개입)이 정해졌다.

## 아직 모르는 것

데이터 API의 접근 가능 여부와 조건, 포화도 측정 정확도, 지표와 실제 판매의 관계.

## 운영 방식 결정 — 2026-10-10

- 결정(사용자가 전달한 금붕부부 결정): 자동화 수준은 승인 후 자동(금붕부부 승인 상품만 등록, 정리도 승인). 소수 상품 베타 운영 후 상품 수·확장 전략을 정한다. 근거: 상품 수가 늘면 리스크와 관리 지점이 함께 늘어난다.
- 리뉴얼은 결정이 아니라 논의 대상이다. 개선·정리 방식 후보와 판정 기준은 에이전트 제안값으로 [운영 방식](../docs/product-selection-agent.md#운영-방식)에 반영했고 결정 대기다.
- 에이전트 이견: 승인 후 자동 업로드에는 등록 자동화 개발이 필요해 기존 후속 자동화 순서와 겹친다. 베타는 수동 업로드를 추천하며 업로드 방식은 미결로 두었다. 20개 규모로는 가격 전략 우열을 판정할 수 없어 베타 목적을 운영 흐름·판정 기준 확인으로 제안했다.
- 반영: 에이전트 설계(운영 방식), 실행 계획(수동 등록 → 베타 운영, 확장 전 조건), STATUS 미결 과제.

## 베타 조건 확정 — 2026-10-10

- 결정(사용자가 전달한 금붕부부 결정): 베타 20개·8주, 승인 상품 수동 업로드.
- 정정: 판정 기준과 리뉴얼 방식은 결정 요청이 아니라 선택지·추천 질의였다. 등록 후 관리 전략 전체(방치·개선·교체·승자 확장·휴면·삭제 후 재등록)로 넓혀 다시 제안했고, 직전 제안의 "1회 개선 후 4주 재관찰"은 판매 원인 해석을 흐린다는 이유로 "방치 기본·4주차 노출 없음만 수정·8주차 유지 또는 교체"로 대체했다. 결정 대기.
- 후속 결정: 베타는 방치 기본·최소 개입(상시 품절·마진·정책 조치, 4주차 노출 없음 상품 수정)으로 운영하고 8주 후 관리 전략을 재정비한다. 결정 주체: 금붕부부 공동.
