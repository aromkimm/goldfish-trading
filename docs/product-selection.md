# 금붕상사 상품 선정 기준

[상품 등록 원칙](product-listing-principles.md)의 검색 전략을 후보 조사에 적용한다. 다음은 평가표 초안이며 지표의 측정 가능성과 유효성을 검증한 뒤 기준·가중치를 확정한다.

| 항목 | 평가 방법 |
| --- | --- |
| 검색 수요·구매 의도 | 고객이 찾는 종류·사용 상황·선택 조건과 검색 결과의 실제 상품을 대조. 검색광고 API 등 수요 자료는 접근 조건·기간·집계 범위를 확인하고 쇼핑 수요와 구분 |
| 상품 적합성 | 공략 검색 조건을 실제 규격·기능·구성이 충족하는지 근거 대조. 자료 부족과 실제 불일치를 구분 |
| 경쟁 밀도 | 쇼핑 검색 결과 상품 수 ÷ 검색량. 상품 수는 판매자 수와 구분하며 비교 기간·검색어를 맞춘다. 단독 선정 기준으로 쓰지 않는다. |
| 마진 구조 | 동일 규격·구성의 경쟁 상품 실구매 총비용과 도매가·수수료·배송비 등 비용 비교. 마진율 분모 명시. 15% 이상은 추정치 — 미확정 제안 기준 |
| 구매 선택 이유 | 가격·구성·배송·정보 중 경쟁 판매처 대비 선택 이유를 근거와 가설로 구분 |
| 공급 안정성 | 재고·출고·송장·품질·교환·반품 조건과 실제 처리 가능 여부 확인 |
| 운영 적합성 | 사이즈·파손·사용법 관련 CS와 평일 낮 주문·품절·긴급 문의 대응 부담 확인 |
| 배송비 구조 | 판매가 대비 배송비 부담과 묶음 판매 가능성 |
| 변동성 | 품절·단가 변경 빈도와 수동 대응 부담 |

- 검증 후보 상품군: 생활공간 정리용품, 데스크 정리용품, 소규모 사업장 운영용품. 판매 품목으로 확정하지 않는다.
- 수요·구매 의도·상품 적합성·경쟁 판매 조건·기여이익을 함께 판단한다. 가중치와 임계값은 미정이며 단일 지표로 선정하지 않는다.
- 추천 결과에는 검색어 가설·출처·비교 조건·공급 조건·미확인 사항을 함께 전달한다. 등록 단계의 반대 근거는 재검토에 반영하며 상품 변경은 금붕부부가 결정한다.
- 초기 제외 기준안: 화장품·식품·전기용품·유아용품 등 인증·표시 검토 부담이 큰 상품군, 사이즈·색상 선택에 따른 반품 부담이 큰 상품. 적용 범위는 금붕부부가 확정한다.
- 확정된 가치관 필터: 캐릭터·라이선스 굿즈, 일회용·일회성 소비 전제 상품, 다이어트·건강기능 과장 상품은 제외한다.
- 단가·시즌성만으로 제외하지 않는다. 재사용 가능한 시즌 상품과 필요한 저가 생활용품은 평가 대상에 포함한다.
