# 공급처·상품 선정 기준

[사업 방향](../PROJECT.md)을 실행 가능한 공급·판매 구조로 구체화한다. 실제 후보 판정은 [STATUS.md](../STATUS.md#공급처-판정), 진행 순서는 [실행 계획](execution-plan.md)을 따른다.

## 공급처 평가와 판정

| 기준 | 직접 확인할 조건 |
| --- | --- |
| 한국 거주자의 거래 자격 | 한국 주소·개인 또는 한국 사업자 명의 가입, 한국 청구주소·결제수단으로 상품대금 지급, 고객 주소로 발주. 한국 사업자등록·현지 법인/주소/EIN·세무 서류 요구 여부 |
| 낱개 위탁 출고 | 선매입·재고 예치 없이 고객 주문 후 1개 발주, 금붕상사 판매자 표시, 송장·포장 조건, 대상 Amazon 판매 허용, 재고·추적·출고/배송 시간과 예외 |
| 반품 처리 | 현지 반품 주소·RMA·라벨·검수·환불 처리 주체, 단순변심/불량/오배송별 기한·운임·재입고비, 원결제 환불/크레딧, 판매자가 직접 할 일 |
| 상품별 수익성 | 실제 SKU·구성·수량별 공급가·배송 견적·수수료·반품 비용·필수 플랜을 경쟁 가능한 판매가와 비교 |

판정은 **가능 확인 / 불가능 확인 / 일부 확인 / 미확인**으로 구분한다. 전체 기준의 판정과 확인한 세부 항목을 함께 적는다. 불가능 확인은 명시적 제한 또는 해당 조건에서의 실패 근거가 필요하다. 자료 부재는 미확인이다.

공식 정책·업체 서면 답변·계정 화면·견적·실행 결과를 출처와 조건으로 연결한다. AI의 요약은 조사 단서이며 독립 근거가 아니다. 공개된 일반 결제 지원은 한국 발급 카드 수용의 증거가 아니고, 해외 배송 지원은 해외 거주 판매자의 자격과 다르다. 개별 시험 성공도 모든 상품·결제수단으로 일반화하지 않는다.

## 대상과 제외 기준

| 구분 | 적용 내용 |
| --- | --- |
| 확정 제외 | 캐릭터·라이선스 굿즈, 일회용·일회성 소비 전제 상품, 다이어트·건강기능 과장 상품 |
| 초기 제외 | 화장품·식품·전기용품·유아용품 등 인증·표시 검토 부담이 큰 상품, 사이즈·색상 선택에 따른 반품 부담이 큰 상품. [근거](../records/2026-10-10-product-selection-agent.md#사업-결정과-적용-범위) |
| 탐색 범위 | 단가·시즌성만으로 제외하지 않음. 특정 공급처·소형 교체 부품에 한정하지 않음. 부품의 호환성·설치·품질 관련 CS 부담도 평가 |

현재 제외 기준 변경은 금붕부부가 판단한다. 조사 중 등장한 상품이 판매 허용·선정된 상품이라는 뜻은 아니다.

## 상품 비교

- 공급처 SKU·브랜드/모델·옵션·치수·재질·호환성·판매 단위와 포함 부품을 고정한다. 사진·상품명 유사성만으로 동일 상품이라 하지 않는다.
- Amazon의 **동일 상품**은 가격·판매자 경쟁을, **대체 상품**은 수요·사용 목적·가격 수용 범위를 확인하는 데 쓴다. 대체 상품도 후보가 될 수 있으나 기존 상품의 수요·리뷰·판매량이 그대로 이전된다고 가정하지 않는다.
- 가격은 고객 결제 총액·수량·배송기간·할인 조건을 맞춘다. 신규 판매자의 리뷰·배송·가격·정보를 함께 비교한다. 최저가나 높은 표시 마진만으로 판매성을 확정하지 않는다.
- Jungle Scout 등의 추정 판매량은 도구·시장·ASIN·조회일·기간과 함께 추정치로 표시한다. 직접 확보하지 않은 값을 실제 조회 결과로 보고하지 않는다.
- 품질은 재질·사양·제조/공급 근거·실제 상품 리뷰·불량/반품 조건으로 사전 평가한다. 공급처 광고·사진·품질검수 문구와 실물 확인을 구분한다.
- 재고·단가 변경, 주문 마감, 추적번호, 취소·배송 사고·호환성 문의·반품에서 우리 처리 업무와 부담을 비교한다. 미측정 시간을 임의의 주당 운영시간으로 확정하지 않는다.

## 손익 계산

통화·환율 기준일·세금 포함 여부·플랜·상품 수량·배송 목적지·견적 유효기간을 표시한다. 미국 내 배송과 국경 간 배송을 구분하고 관세·통관/취급비의 부담 주체를 확인한다.

- **주문당 기여이익 = 판매대금 − 공급가 − 배송비 − Amazon 판매 수수료 − 결제·환전·주문 처리비 − 판매자 부담 세금·통관비 − 기대 반품·불량·사고 비용.** 판매대금에는 고객 배송비를 포함하고 판매자가 보유하지 않는 대행 징수 세금은 제외한다. 수수료는 실제 과금 기준으로 계산하며 중복 차감하지 않는다.
- **월 손익 = 주문별 기여이익 합계 − 월 고정비.** Accio·공급처·Amazon·시장 도구의 필수 구독료 등을 포함한다. 판매량 가정에 따라 월 손익은 추정치이며, 고정비를 건당 배분할 때는 가정 주문 수를 명시하고 월 손익에서 중복 차감하지 않는다.
- **허용 배송비 = 판매대금 − 배송비 외 주문당 비용 − 목표 기여이익.** 배송 견적 전의 탐색 기준일 뿐 실제 이익 확정이 아니다. 목표 이익은 합의값 또는 해당 비교의 가정으로 표시한다.
- 반품률을 모르면 영으로 두지 않는다. 미확정 비용을 제외한 잠정 이익과 제외 항목을 밝히고, 반품 1건의 손실·가정 반품률별 민감도를 별도로 계산한다. 월 고정비·품절·가격 인하에 대한 민감도도 함께 본다.

최소 마진율·공통 건당 이익 합격선·판매량 목표는 [미결 과제](../STATUS.md#미결-과제)에서 관리한다. 근거 부족은 추가 확인, 비교 조건을 맞춘 손실·명시적 판매 불가는 제외 사유로 제시한다. 최종 상품·가격 선택은 금붕부부가 한다.
