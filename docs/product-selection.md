# 금붕상사 상품 선정 기준

판매 가능성과 운영 부담을 함께 비교해 등록 검토할 상품을 고른다. [등록 원칙의 검색 전략](product-listing-principles.md#고객과-검색-전략)을 후보 조사에 적용하며, 상품 선정과 변경은 [공동 결정 원칙](../AGENTS.md#역할과-책임)을 따른다.

## 대상과 제외 기준

| 구분 | 적용 내용 |
| --- | --- |
| 확정 제외 | 캐릭터·라이선스 굿즈, 일회용·일회성 소비 전제 상품, 다이어트·건강기능 과장 상품 |
| 평가 대상 | 단가·시즌성만으로 제외하지 않음. 재사용 가능한 시즌 상품과 필요한 저가 생활용품 포함 |
| 검증 후보 상품군 | 생활공간 정리용품, 데스크 정리용품, 소규모 사업장 운영용품. 판매 품목 확정 아님 |
| 초기 제외 기준 | 화장품·식품·전기용품·유아용품 등 인증·표시 검토 부담이 큰 상품군, 사이즈·색상 선택에 따른 반품 부담이 큰 상품. 판매 경험 후 재정비. [결정 근거](../records/2026-10-10-product-selection-agent.md#결과) |

## 평가 방법

아래는 평가표 초안이다. 지표의 측정 가능성과 유효성을 검증한 뒤 기준·가중치를 확정한다. 수요·상품 적합성·경쟁 판매 조건·기여이익을 함께 판단하며 단일 지표나 근거 없는 점수로 선정하지 않는다.

| 항목 | 확인할 자료·판단 방법 |
| --- | --- |
| 같은 유형 포화도 | 핵심 비교 지표. 같은 사진·유형의 판매자 수를 구분하며 측정 방식·표본 한계는 [선별 설계](product-selection-agent.md#포화도-측정)를 따름. 네이버 전체 경쟁으로 일반화하지 않음 |
| 검색 추세 | 상대 검색 관심의 증감·계절성. 절대 검색량이나 판매량과 구분 |
| 진입 장벽 | 상위 경쟁 상품의 리뷰·판매 규모. 자동 측정 출처는 미확인 |
| 검색 수요·구매 의도 | 고객이 찾는 종류·사용 상황·선택 조건과 실제 검색 결과 상품 대조. 수요 자료의 접근 조건·기간·집계 범위를 확인하고 쇼핑 구매 수요와 구분 |
| 상품 적합성 | 공략 검색 조건을 실제 규격·기능·구성이 충족하는지 근거 대조. 자료 부족과 실제 불일치 구분 |
| 경쟁 밀도 | 쇼핑 검색 결과 상품 수 ÷ 검색량. 현재 도구는 11번가 상품 수와 네이버 검색량을 사용하므로 마켓 차이의 한계를 표시. 상품 수와 판매자 수를 구분하고 비교 기간·검색어를 맞춤. 단독 선정 기준으로 사용하지 않음 |
| 수익성 | 동일 규격·구성의 경쟁 최저가·중앙가 두 시나리오와 공급가·수수료·배송비 등 비교. 기여이익은 [공통 산식](../PROJECT.md#운영-및-평가), 마진율은 분모 명시 |
| 구매 선택 이유 | 가격·구성·배송·정보에서 경쟁 판매처 대비 선택받을 이유를 근거와 가설로 구분 |
| 공급 안정성 | 재고·출고·송장·품질·교환·반품 조건과 실제 처리 가능 여부 |
| 운영 적합성 | 사이즈·파손·사용법 관련 CS, 평일 낮 주문·품절·긴급 문의 대응 부담 |
| 배송비 구조 | 판매가 대비 배송비 부담과 묶음 판매 가능성 |
| 변동성 | 품절·단가 변경 빈도와 수동 대응 부담 |

검색량·경쟁 밀도·같은 유형 포화도 임계값·마진 기준·가중치는 미정이다. 도구의 선별 조건은 [선별 설계](product-selection-agent.md#선별-조건)의 추정·제안값이며 사업상 합격선이 아니다. 후보별 관측과 비용 자료를 검증한 뒤 정하며 미검증 제안값을 합격선으로 적용하지 않는다. 확인/추정/모름은 [수치 표기](../AGENTS.md#수치-표기)를 따른다.

## 후보 선별 평가

평가 질문은 **선별 통과 후보가 단순한 후보 선택보다 무광고 신규 스마트스토어에서 판매를 시험할 가치가 있는 상품을 더 많이 담고, 손해 볼 상품을 더 잘 걸러내는가**다. 평가는 세 단계로 나눈다.

| 단계 | 범위 | 판단 근거 |
| --- | --- | --- |
| 판매 전 비교 평가 | [처리 흐름](product-selection-agent.md#처리-흐름) 1~7단계 산출물. 선별 통과 후보와 비교군을 블라인드로 [평가용 등급](#판정과-보고)을 매겨 비교 | 정량 측정값은 에이전트가 계산. 금붕부부의 [정성 평가](#정성-평가)는 참고 자료 |
| 판매 가능 조건 | 8단계 [판매 가능 조건 확인](product-selection-agent.md#판매-가능-조건-확인). 비교 평가에 넣지 않고 판매 실험 후보에만 적용 | 판매 조건서·반려 사유 |
| 실판매 | [실판매로 확인할 것](#실판매로-확인할-것) | 주문·기여이익·운영 부담 |

API 호출 성공·문서 완성도나 평가자의 구매 의향을 판매성의 정답으로 사용하지 않는다. 이 평가 방법은 사업상 수익 목표·판매 승인선·실험 규모를 확정하지 않는다.

### 평가 기준

| 기준 | 확인할 내용 | 오류가 선별에 미치는 영향 |
| --- | --- | --- |
| 후보 풀 | 모집 검색어·상품군·사용 상황의 범위, 수요와 공급의 연결, 기존 검색어 밖 후보의 발견 경로. 공급 출발 자체를 결함으로 보지 않음 | 좋은 후보가 탐색 범위에서 빠짐. 범위 밖 상품을 찾는 능력은 별도 탐색 실험 없이는 판단 불가 |
| 수요 신호 | 대표·공략 검색어의 구매 의도와 실제 규격·기능·구성 일치, 수요 자료의 기간·범위·범위값 해석 | 다른 상품의 수요로 통과, 통합검색 관심을 구매 수요로 오인 |
| 경쟁 측정 | 11번가 자료가 네이버를 반영하는지 별도 표본 대조. 같은 사진·동일 상품·대체 상품 구분, 옵션·수량·배송비·할인 조건의 일치 | 경쟁이 치열한 상품을 기회로 오판. 네이버 자료가 없으면 마켓 간 타당성은 판단 불가 |
| 수익성 | 계산 정확성과 판매가 현실성을 별도 확인. 적용 조건을 확인한 공급가·배송비·수수료·반품 등 비용, 기여이익·손익분기 조건 | 팔아도 남지 않거나 받을 수 없는 가격에 의존. 최저판매준수가를 고객의 가격 수용 근거로 오용 |
| 선별 조건 | 조건별 근거, 필터 순서, 누락값 처리, 가격 가정에 대한 민감도, 모두 부적합할 때 통과 없음 | 손해 볼 후보를 통과시키거나 쓸 만한 후보를 걸러냄. 설명만 타당한 기준을 성능 검증으로 취급 |
| 발견 가능성 | 네이버 일반 검색의 관련·대체 상품과 상위 판매처 조건, 공략 검색 조건과 무광고 유입 가설 | 같은 사진 판매자가 적다는 이유만으로 노출 기회가 있다고 오판 |
| 구매 이유 | 동일·대체 상품 대비 고객 결제 총액·배송·구성·정보·신뢰, 그 필요를 가진 고객이 우리 판매처를 선택할 근거 | 지표는 좋아도 선택받을 이유가 없음. 상세페이지 개선이 가격·배송 열세를 상쇄한다고 가정 |
| 실제 결과물 품질 | 최신 실행의 자동 선별과 최종 인계를 각각 검토. 상품별 근거·반대 근거·모름, 통과·탈락 후보의 차이 | 구조의 결함이 실제 결과에 드러나는지 놓치거나, 중간 목록의 문제를 최종 결과의 실패로 단정 |
| 학습 루프 | 선별과 후속 검토·판매 결과의 연결, 오류 발견·원인 구분·수정·새 표본 재평가 | 같은 오류 반복, 보정에 쓴 상품의 개선을 새로운 상품에 대한 성능으로 오인 |

**공급·운영 적합성은 판매 실험 검토를 위한 별도 필수 조건**이며 8단계에서 확인한다. [판매 가능 조건](product-selection-agent.md#판매-가능-조건-확인)과 위 상품 평가의 운영 적합성을 대조한다. 필요한 조건의 누락·판매 불가·대응 방법 부재를 수요나 마진으로 상쇄하지 않는다. 이미지 사용 불허 등 주의 항목은 기존 반려 기준에 따라 대안을 확인하며 일률적으로 제외하지 않는다.

### 판정과 보고

기준별로 다음 판정을 사용하고 근거·반대 근거·영향·확인 범위를 함께 적는다. 등급은 평가 판단이며 판매 확률이나 실적이 아니다. 평가 전에 각 기준에서 확인할 자료와 적용 범위를 고정한다.

| 판정 | 적용 조건 |
| --- | --- |
| 충분 | 해당 범위의 핵심 질문을 근거로 확인했고 결론을 뒤집는 결함이 관측되지 않음. 구조 평가의 충분을 실제 판매 성능으로 확대하지 않음 |
| 부분 | 일부는 근거로 확인했으나 검증 범위·처리에 한계가 있음. 확인한 부분과 남은 질문을 분리 |
| 미흡 | 확인된 오류·누락된 처리·반대 근거가 해당 결론을 지지하지 못함. 구체적인 사례와 영향을 제시 |
| 판단 불가 | 필요한 자료·접근·실행 결과가 없어 타당성을 판정할 수 없음. 필요한 자료와 확보 방법을 명시 |

판매 전 비교 평가는 상품마다 아래 **평가용 등급**과 근거·반대 근거·모름을 남긴다. 평가용 등급은 비교 측정용이며 `judgments`에 저장하지 않고 평가 파일에만 둔다. 원가는 공급가와 1개 주문 배송비이며 같은 상품은 같은 사진이나 상품명·규격·수량이 일치하는 경쟁 상품이다. 구체적인 수치 조건은 평가마다 판정 전에 고정해 기록한다.

- **시험해 볼 만함:** 같은 상품·같은 규격의 무료배송 판매가(11번가 표시가)가 원가보다 여유가 있고, 대표 검색어 상위 상품이 같은 종류이며, 확인된 반대 근거가 없다.
- **불확실:** 같은 상품 가격 근거가 부족하거나 포화·검색 의도·옵션 기준 등 핵심 근거가 엇갈린다.
- **제외:** 같은 상품 판매가 기준 적자, 다른 상품·규격 가격에 기댄 마진, 제외 기준 해당 등 반대 근거가 확인됐다.

7단계 검토와 판매 조건 확인 뒤의 상품별 결론은 다음 판정 등급을 쓰고 `judgments`에 저장한다. 기준별 등급을 평균 내거나 모름을 영으로 바꾸지 않는다.

- **판매 실험 검토 가능:** 공급·운영 필수 조건을 확인하고, 판매 가설을 시험할 근거와 검증할 불확실성을 설명할 수 있음. 실제 판매 승인·성공 예측과 구분한다.
- **추가 확인:** 핵심 근거·필수 조건이 없거나 충돌이 해소되지 않음. 확인 대상과 결과에 따라 달라질 판단을 적는다.
- **제외:** 기존 제외 기준·확인된 판매 불가 조건에 해당하거나, 비교 조건을 맞춰도 판매 가설을 지지하지 않는 반대 근거가 있음. 이유와 재검토 조건을 적는다.

보고에는 평가 버전·자료 시점·범위·미실행 항목, 기준별 판정, 상품별 결론, 비교 측정값, 개선 우선순위를 담는다. 개선은 확인된 판매 불가·손실 위험, 후보 선정·누락을 바꾸는 오류, 업무 부담 순으로 검토하되 영향 범위와 근거의 확실성을 함께 설명한다. 발생 빈도·손실 규모가 모르면 우선순위는 잠정 판단으로 표시한다. 필요한 기록은 [기록 양식](../records/TEMPLATE.md)에 남기며 점검용 문서나 이력을 중복 생성하지 않는다.

### 평가 절차

1. **대상과 비교 조건을 고정한다.** 코드·설정·실행일·후보 모집 조건·전체 후보·선별 통과 여부·원자료 시점을 연결한다. 후보 생성 → 자동 선별 → 7단계 검토의 결과를 구분한다. 실제 출력이 없으면 구조 평가까지만 수행한다.
2. **구조와 실제 동작을 대조한다.** 코드·설정·실행 절차·기록을 읽고 누락값, 잘못된 검색어·가격, 모두 부적합한 후보군, 후보군 구성 변화 등으로 필터·보류 동작을 확인한다. 합성 입력은 재현용으로 표시한다. 구조·합성 시험 통과는 해당 동작의 증거이며 실제 상품 정확도가 아니다.
3. **보정용과 평가용 상품을 분리한다.** 임계값·가격 보정에 사용한 상품은 개발 사례로 남기고 새 상품 성능 평가에서 제외한다. 평가 배치는 별도 DB로 모으고 이전 DB의 상품번호를 넣지 않는다. 결과를 보고 설정을 바꾸면 그 표본은 개발 사례가 된다.
4. **표본 규모와 비교군을 결과를 보기 전에 고정한다.** 그룹은 선별 통과 전체·무작위·사전 정의한 단순 규칙·탈락 후보(탈락 사유별로 고르게)로 두고, 무작위·단순 규칙은 선별 통과와 같은 모집 범위·제외 기준·선택 수에서 고른다. **표본 규모는 선별 통과·무작위·단순 규칙 각 40개 이상, 탈락 후보 40개 이상**이다〔추정 — 비율 20% 대 50% 차이를 유의수준 5%·검정력 80%로 판별하는 그룹당 규모〕. 선별 통과가 부족하면 같은 수집 조건의 배치를 추가하며 선별 조건을 바꾸지 않는다. 배치 사용 규칙·추출 스크립트·시드는 결과를 보기 전에 정하고, 실행 후에는 그룹별 개수만 확인한다. 겹치는 상품은 한 번만 판정한다.
5. **선별 통과 여부를 가리고 판정한다.** 그룹·선별 통과 여부·마진·검색량을 뺀 자료(경쟁가 계산 상품명·가격·배송, 상품정보고시, 옵션·배송·반품, 대표 키워드 상위 상품명)로 판정 대상 전부를 상품번호 순으로 판정한다. 판정은 선별을 실행한 에이전트와 분리한 별도 에이전트가 하고, 금붕부부가 같은 자료로 일부를 직접 판정해 판정자 간 일치도를 확인한다. 분리하지 못하면 독립성의 한계를 남긴다.
6. **근거 자체를 검증한다.** 원자료 재해석만으로 데이터 정확성이 검증되지는 않는다. 같은 데이터만 사용했다면 내부 정합성 평가라고 명시한다. 상식은 가설·확인 질문을 만드는 데 쓰고 현재 시장의 사실 근거로 삼지 않는다. 네이버 표본은 허용된 접근 경로·제공 자료로 확인하며 크롤링·차단 우회를 하지 않는다.
7. **비교하고 개선 후보를 분리한다.** 아래 측정값을 계산하고 결론을 낸다. 오류를 수집·해석·선정·후속 검토로 나눠 개선하며, 사후 분석에서 나온 개선 아이디어는 새 표본으로 다시 평가하기 전까지 성능 근거로 쓰지 않는다.

### 측정값

그룹별로 계산하고 선별 통과 대 각 비교군의 비율 차이를 95% 신뢰구간(Newcombe·Wilson 구간)과 정확 검정 p값으로 제시한다. 신뢰구간이 0을 포함하면 '차이 없음'이며 이것도 결론이다. 모름은 분모에서 빼고 건수를 함께 적는다.

| 측정값 | 계산·해석 |
| --- | --- |
| 평가용 등급 분포 | 시험해 볼 만함·불확실·제외 비율. 탈락 표본의 시험해 볼 만함 비율은 놓친 후보 지표이며 전체 재현율이 아님 |
| 가격 근거 오류율 | 경쟁가 계산에 쓴 상품 다수가 같은 상품·규격이 아닌 비율 |
| 같은 상품 판매가 적자 비율 | 같은 상품 무료배송 최저가가 원가 이하인 비율. 같은 상품 가격이 없으면 모름 |
| 검색 의도 불일치율 | 대표 키워드 상위 상품 다수가 다른 종류인 비율 |
| 동일 상품 포화 | 같은 사진 판매자 수의 중앙값·사분위 |
| API로 확인되는 판매 불가 | 8단계 자동 검사 중 사람 입력 없이 판정되는 항목을 저장된 최신 스냅샷에 적용한 비율. 판매 조건 확인 자체를 대신하지 않음 |
| 판정자 일치도 | 별도 에이전트와 금붕부부가 함께 판정한 상품에서 등급이 같은 비율. 낮으면 등급 기준을 다시 정의 |
| 실제 업무 효용 | 검토·추가 조사·수정 시간을 포함한 유효 후보 확보 시간. 개발 시간은 분리 |

합격 비율·성능 개선 목표는 미정이다. 먼저 오류 유형과 비교군 성능을 측정하며 임의의 만점·가중치로 품질을 확정하지 않는다. 후보군 전체가 부적합하면 통과 없음이 적절한 결과다.

### 정성 평가

금붕부부가 판매 전 비교 평가의 판정 표본 중 선별 통과 후보와 비교군을 섞은 목록(그룹 가림)에서 **각자 3~5개**의 도매 상세페이지를 훑어보고 '구미 당김 / 별로'와 한 줄 메모를 남긴다. 통계에는 쓰지 않으며, 에이전트의 블라인드 판정과 대조해 판정이 놓친 상품 매력·위험과 판정 기준의 현실성을 점검하는 참고 자료다. 그룹 대응표는 화면과 분리해 둔다.

### 실판매로 확인할 것

판매 가능 조건을 통과한 상품으로 [소규모 검증 흐름](execution-plan.md#소규모-검증-흐름)에 따라 선별 통과 후보와 안전·공급 조건을 충족한 비교군의 상품군·가격대·등록 시점·등록 자료 품질·관찰 기간을 가능한 한 맞춘다. 비교군이 없으면 선별의 효과는 판정할 수 없다. 상품마다 원래 가설·선정 경로·변경한 가격/콘텐츠·품절 기간을 남긴다.

- 주된 결과는 취소·반품을 반영한 주문·기여이익과 상품당 판매 가능 기간이다. 관찰 종료일까지 주문이 없는 상품도 포함하며 취소·반품 미확정분은 별도 표시한다.
- 노출 → 클릭 → 주문은 실패 위치를 찾는 진단 지표다. 클릭률은 클릭/노출, 전환율은 주문/방문 등 실제 확보한 분모 정의를 고정한다. 미제공·미측정은 모름이다.
- 노출이 부족하면 구매 전환 가능성은 판정 보류지만, 무광고 유입 가설은 지지되지 않은 결과로 남긴다. 노출된 상품만 골라 선별 성능을 계산하지 않는다.
- 비용·운영 부담을 함께 보고, 등록 품질·가격·계절 차이와 관찰 기간이 짧은 영향을 분리한다. 판매 부진을 곧바로 상품 선정 실패로 단정하지 않고 선별·등록·가격·공급의 원인을 대조한다. 판매 실험 수량·기간은 [소규모 검증 흐름](execution-plan.md#소규모-검증-흐름)을 따르고 손실 한도는 금붕부부 판단 사항이다.

## 선별 결과와 인계

선별 결과는 위 평가 항목의 근거·비교 조건·판단·미확인 사항을 포함한다. 선별 뒤 [판매 가능 조건 확인](product-selection-agent.md#판매-가능-조건-확인)을 거쳐 판매 조건서를 전달한다. 등록 단계가 사용할 상품 정보는 [상품 브리프](../agents/product-listing/README.md#상품-브리프)를 참고해 전달한다.

자료 부족은 부족한 항목과 영향을 표시한다. 등록 단계에서 새로운 반대 근거가 확인되면 후보 평가에 반영하고, 상품 변경이 필요하면 재검토 의견을 제시한다. 실제 선정 상태와 남은 결정은 [STATUS.md](../STATUS.md)에서 관리한다.
