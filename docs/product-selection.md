# 금붕상사 상품 선정 기준

다음은 평가표 초안이다. 지표의 측정 가능성과 유효성을 검증한 뒤 가중치·임계값을 확정한다. 지표 수집과 계산 방식은 [상품 추천 에이전트 설계](product-selection-agent.md)에서 관리한다.

| 항목 | 평가 방법 |
| --- | --- |
| 동일 상품 포화도 | **핵심 지표.** 같은 유형 상품을 이미 판매 중인 판매자 수. 11번가 상품명 검색 결과에서 상품명이 비슷한 판매자를 센다(사진이 달라도 포함). 같은 사진만 세면 경쟁을 놓친다는 것이 네이버 표본으로 확인됐다. |
| 검색 수요 | 네이버 검색광고 API의 검색량을 후보 데이터로 사용. 접근 조건·제공 범위와 적정 구간 확인 |
| 검색 추세 | 네이버 검색어 트렌드의 최근 3개월 증감과 계절 지수. 상대값이며 검색량이 아니다 |
| 경쟁 밀도 | 11번가 검색 결과 상품 수 ÷ 네이버 검색량. 상품 수는 판매자 수와 구분하며 비교 기간·검색어를 맞춘다. 단독 선정 기준으로 쓰지 않는다. |
| 마진 구조 | 판매가를 경쟁 최저가와 경쟁 가격 중앙값 두 시나리오로 각각 계산하고 도매가·수수료·배송비 등 비용과 비교. 마진율 분모 명시. 네이버 보정 후 경쟁 중앙가 기준 15% 이상, 경쟁 최저가 기준 적자 아님을 추천 조건으로 쓴다(추정치 — 미확정 제안 기준) |
| 배송비 구조 | 판매가 대비 배송비 부담과 묶음 판매 가능성 |
| 변동성 | 품절·단가 변경 빈도와 수동 대응 부담 |
| 진입 장벽 | 상위 경쟁 상품의 리뷰·판매 규모. 네이버 표본에서 결정적이었으나 자동 측정 출처가 없어 모름 |

- 동일 상품 포화도를 핵심 지표로 두고 경쟁 밀도와 마진 구조에 높은 비중을 둔다. 가중치와 임계값은 미정이다.
- 초기 제외 기준: 화장품·식품·전기용품·유아용품 등 인증·표시 검토 부담이 큰 상품군, 사이즈·색상 선택에 따른 반품 부담이 큰 상품. 판매 경험이 쌓이면 범위를 재정비한다.
- 확정된 가치관 필터: 캐릭터·라이선스 굿즈, 일회용·일회성 소비 전제 상품, 다이어트·건강기능 과장 상품은 제외한다.
- 단가·시즌성만으로 제외하지 않는다. 재사용 가능한 시즌 상품과 필요한 저가 생활용품은 평가 대상에 포함한다.

## 변경 및 적용

- 후보별 평가 결과와 근거는 [검증 기록](../records/TEMPLATE.md)으로 남긴다.
- 금붕부부가 확정한 현재 기준을 적용하며, 미확정 항목은 제안값으로 표시한다.
- 현재 미결 항목은 [STATUS.md](../STATUS.md)에서 관리한다.
