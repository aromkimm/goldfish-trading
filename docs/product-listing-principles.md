# 상품 등록 원칙

Amazon 판매 검토 상품의 구매 판단에 필요한 정보를 정확히 제공한다. 상품 선택·경쟁 비교는 [선정 기준](product-selection.md), 실제 판매 개시는 [착수 조건](execution-plan.md#판매-착수-조건)을 따른다.

## 판매 대상과 검색 정보

- 상품명·브랜드·모델·규격·호환성·옵션·수량·이미지·가격이 동일한 판매 대상을 가리켜야 한다. 공급처명이나 금붕상사를 제조 브랜드로 임의 기입하지 않는다.
- 기존 ASIN에 판매자로 참여할지 신규 상품으로 등록할지는 실제 동일성·브랜드/카테고리 권한과 최신 Amazon 등록 조건을 확인해 결정한다. 유사 대체 상품을 다른 상품의 ASIN에 연결하지 않는다.
- 고객의 사용 목적·선택 조건을 중심으로 검색어와 설명을 작성한다. 검색량·경쟁 표현은 조사 자료이며 상위 노출이나 판매를 보장하지 않는다.
- 가격 외의 구매 이유도 구성·품질·배송·신뢰의 근거로 설명한다. 근거 없는 우수성·후기·성과·호환성 주장을 만들지 않는다.

## 사실과 자산

- 공급처 기재 사실·자체 확인·추정·모름을 구분한다. 사진만으로 재질·규격·성능·호환성을 확정하지 않는다.
- 이미지·문구 사용 및 편집 권한이 대상 시장·채널에 적용되는지 확인한다. 원본의 의미·수치·조건을 보존하며 상품 외형·색상·구성을 왜곡하지 않는다.
- 필요한 치수·부품 구성·설치 조건·제약을 읽기 쉽게 제시한다. 참고 옵션·소품이 실제 포함품으로 오인되지 않게 한다.
- 내부 조사 메모와 출처 관리용 표기를 고객 설명에 노출하지 않는다. 고객 판단에 필요한 불확실성이나 사용 제약은 숨기지 않는다.

## 게시 전 확인

- 실제 Amazon 계정에서 대상 카테고리의 필수 정보·이미지·브랜드·변형/옵션·안전 표시와 게시 권한을 확인한다. 일반 등록 가이드를 상품별 승인으로 간주하지 않는다.
- 고객에게 제시할 배송일·발송지·판매자 정보·반품 조건이 실제 처리 가능한지 대조한다. 공급처 B2B 반품 규정을 소비자 정책으로 그대로 복사하지 않는다.
- 로컬 초안·구조 검사·AI 검수와 실제 채널 표시 검수를 구분한다. 비용·권한·필수 정보가 미확인이면 확정 문구로 게시하지 않는다.
- 판매 후 유입·주문·문의·반품을 보고 수정하되, 관측 전후 변화만으로 문구·키워드의 효과를 확정하지 않는다.
